# 100 ideas, ranked

Scored impact × feasibility × fit. Fit matters most: this pitch is *private
contribution, public settlement*, and a feature that does not sharpen that
is clutter no matter how nice it looks.

## Tier 1 — build first (sharpen the pitch, judges will notice)

| # | Idea | Why it wins |
|---|---|---|
| 1 | **Merkle allocation verifier** — paste an address, recompute the proof in-browser, check it against the on-chain root | The whole "nobody has to trust the operator" claim, made touchable |
| 2 | **Transaction lifecycle toasts** — pending → mined → confirmed, with hash and revert reason | Every action costs a signature; the demo lives or dies on feedback |
| 3 | **Command palette (⌘K)** — search raises, desks, wallets; jump to any action | One keystroke makes a dense app look navigable |
| 4 | **Privacy ledger** — side-by-side of exactly what is sealed and what is public, per raise, read from chain | States the thesis on the page instead of in the pitch |
| 5 | **Proof timer** — real elapsed ms for each ZK proof, with the circuit named | Turns a 30s wait from "is it broken" into "it is proving" |
| 6 | **Portfolio** — holdings, claims and fee positions across every raise | The screen a returning user actually wants |
| 7 | **Chart crosshair + OHLC tooltip** | The single most-expected trading interaction |
| 8 | **Count-up figures** — live numbers roll to their new value | Cheap, and makes every update legible |
| 9 | **Graduation moment** — a curve hitting its target gets a HUD stamp and a state change | The one celebratory beat the product earns |
| 10 | **Watchlist page** from on-chain saves |
| 11 | **Node-down banner** — detect a dead RPC and say so |
| 12 | **Volume histogram** under the price chart |
| 13 | **Onboarding tour** for a first-time judge |
| 14 | **aria-live transaction announcements** |
| 15 | **Copy confirmation** micro-interaction on every address |
